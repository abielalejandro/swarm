🐝 Swarm v1.0 — Sistema de Negociación Multi-Agente con IA

Un sistema autónomo de negociación donde múltiples agentes de IA con agendas ocultas, emociones y memoria negocian contratos ejecutables. Incluye un guardián constitucional que aplica reglas inmutables y un psicólogo que detecta engaños.

🚀 Instalación Rápida

1. Clonar / Descargar el proyecto

# Si tienes el ZIP
unzip swarm_v1.0.zip
cd swarm_v1.0

# O si es desde Git
git clone <tu-repo>
cd swarm_v1.0

2. Crear archivo de configuración

cp .env.example .env

3. Configurar el proveedor LLM

nano .env
Configuración mínima (OpenAI): 
LLM_PROVIDER=openai
LLM_MODEL=gpt-4o-mini
LLM_API_KEY=sk-xxxxxxxxxxxx

4. Dar permisos a los scripts

chmod +x scripts/*.sh

5. Construir y desplegar

# Opción 1: Usar el script automático
./scripts/deploy.sh

# Opción 2: Usar Make
make build
make up

# Opción 3: Usar Docker Compose directamente
docker compose build
docker compose up -d

6. Verificar que todo funciona

make health
Salida esperada: 
✅ Orchestrator API (8000)
✅ Guardian API (8001)
✅ Psychologist API (8002)
✅ Meta-Psychologist API (8003)
✅ Executor API (8004)
✅ Dashboard (8501)

7. Abrir el Dashboard

open http://localhost:8501

🤖 Proveedores LLM Soportados

El sistema soporta cualquier proveedor con solo cambiar 3 variables en .env.

Proveedor Código Modelo Ejemplo API Key
OpenAI openai gpt-4o-mini sk-...
DeepSeek deepseek deepseek-chat sk-...
Anthropic anthropic claude-3-sonnet-20240229 sk-ant-...
Groq groq llama-3.3-70b-versatile gsk_...
Azure azure gpt-4 Azure key
Ollama ollama llama3 dummy
LM Studio lm_studio local-model dummy
Custom custom tu-modelo tu-key

Ejemplos de configuración:

DeepSeek (recomendado por precio/calidad): 
LLM_PROVIDER=deepseek
LLM_MODEL=deepseek-chat
LLM_API_KEY=sk-xxxxxxxxxxxx
Groq (muy rápido): 
LLM_PROVIDER=groq
LLM_MODEL=llama-3.3-70b-versatile
LLM_API_KEY=gsk_xxxxxxxxxxxx
Ollama (local y gratuito): 
LLM_PROVIDER=ollama
LLM_MODEL=llama3
LLM_API_KEY=dummy
OLLAMA_URL=http://localhost:11434/v1

📡 Uso de la API

1. Ver agentes disponibles

curl -s http://localhost:8001/agents | jq '.'

2. Iniciar una negociación

curl -X POST http://localhost:8000/negotiate \
  -H "Content-Type: application/json" \
  -d '{
    "goal": "Diseñar una microfactoría sostenible con reducción de carbono del 30%",
    "deadline": "2026-12-31",
    "budget": 500000
  }'

3. Ver estado de una sesión

SESSION_ID="session_20260115_143022"
curl -s http://localhost:8000/session/$SESSION_ID | jq '.'

4. Interrogar a un agente

curl -X POST http://localhost:8002/interrogate \
  -H "Content-Type: application/json" \
  -d '{
    "agent_id": "Engineering_001",
    "style": "standard"
  }' | jq '.'

5. Ver la Constitución

curl -s http://localhost:8001/constitution | jq '.'

6. Ejecutar un contrato

curl -X POST http://localhost:8004/execute \
  -H "Content-Type: application/json" \
  -d '{
    "contract_id": "test_001",
    "state_machine": {
      "states": [
        {"resource_type": "aws_instance", "resource_name": "test_server"}
      ],
      "transitions": {}
    },
    "environment": "sandbox",
    "auto_approve": true
  }' | jq '.'

🔧 Solución de Problemas

Problema Solución
Connection refused docker ps y docker compose restart
OPENAI_API_KEY not set Verificar LLM_API_KEY en .env
Construcción lenta (>5 min) docker compose pull
psychologist no construye DOCKER_BUILDKIT=0 docker compose build psychologist
Agentes no responden docker compose restart agents
Redis no conecta docker exec swarm_redis redis-cli ping
Reset completo ./scripts/reset_swarm.sh
